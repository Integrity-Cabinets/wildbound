# Wildbound

Playable Chapter One of an original creature-collecting RPG. Open `dist/index.html` in a browser to play.

- `python3 build.py` rebuilds the game from `src/`.
- `python3 build.py --data` also rebuilds the art and data bundle (needs `pip install pillow`).
- `CLAUDE.md` explains the layout, the rules and the backlog.
